# Privacy Policy

Last updated: October 7, 2026

This application is a personal WHOOP API integration created for accessing and analyzing the authorized user's own WHOOP data.

## Data Access

The application may access WHOOP data authorized by the user, including recovery, cycles, sleep, workouts, profile information, and body measurements.

## Use of Data

WHOOP data is used solely for personal health, fitness, recovery, sleep, and training analysis. The data is not sold, rented, or used for advertising.

## Data Sharing

The application does not sell or share WHOOP data with third parties except where necessary to provide the requested analysis or where required by law.

## Authorization

Access to WHOOP data is provided through WHOOP's OAuth authorization process. The user can revoke access through their WHOOP account.

## Security

Reasonable measures are used to protect authentication credentials and accessed data. OAuth client secrets and access tokens are not intentionally made public.

## Contact

For questions regarding this Privacy Policy, please contact the application owner through this GitHub repository.
